Olum はデフォルトで XSS（スクリプトの注入）からあなたを守ります。意図的にオプトアウトしない限り、すべての値はエスケープされます。

- **デフォルトでは**、テキストと属性の中のすべての `{expr}` は（`olum.esc` によって）HTML エスケープされます。そのためユーザーデータに含まれる `<script>` はテキストとして表示されて実行されず、`<` や `"` のような文字がページを壊すこともありません。
- **本物の HTML を挿入する**（信頼できる内容のみ）には、要素に `html="expr"` を付けるか、インラインで `olum.html(value)` を使います。[生の HTML](/docs/raw-html)を参照してください。
- **スロットの内容**（`children`）は、あなた自身のテンプレートから来るものなので HTML として挿入されます。[スロット](/docs/slots)を参照してください。

:::danger{icon="🔒"}
ユーザーの内容を `html=` や `olum.html()` に渡してはいけません。ユーザーが提供した HTML をどうしても表示する場合は、先にサニタイズしてください。
:::
